# Haven

Haven is an ongoing study of what technology feels like when it asks for less attention.

It began as a set of questions about quiet, orientation, place, and human-scale tools. Some early branches became larger in language than they were in substance. They remain part of the record, but they are not the work.

The work is the things that survive being made.

## Current

- [Haven Artifacts](https://github.com/colemanvii/haven-artifacts) — small finished objects.
- [Haven Pay](https://github.com/colemanvii/haven-pay) — a working payment utility.

Other experiments will appear here when they exist as objects, not merely as names.

## Rule

Build first. Name later.

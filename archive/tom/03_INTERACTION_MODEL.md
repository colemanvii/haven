# Interaction Model

TOM has one primary input: a physical wheel.

Interaction begins with rotation, not tapping.
There is no instant response.

Each action introduces a brief, intentional delay before feedback is given.
This delay is not lag.
It is a breath.

The wheel provides proprioceptive orientation.
The user knows where they are through feel, not visual scanning.

Output is minimal:
- One line of text
- A soft amber glow
- Subtle physical resistance

TOM never demands attention.
It waits.

The interaction loop is:
Hand → Wheel → Pause → Response

This loop is the core of TOM.

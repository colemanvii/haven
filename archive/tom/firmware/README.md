# TOM Firmware

The firmware is responsible for enforcing calm.

It introduces intentional latency, governs physical input, and controls light and text output in a way that supports the human nervous system.

Speed is not a success metric.
Stability and predictability are.

## Core Responsibilities
- Read wheel input
- Apply intentional delay
- Control glow ramping
- Render single-line text
- Remain functional without network access

## Principle
If the firmware feels impatient, it is wrong.
